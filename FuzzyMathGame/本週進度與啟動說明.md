# 本週實作

雙擊「啟動程式.bat」，保持視窗開啟，再開 http://127.0.0.1:5000/ 。已有伺服器在執行時，先關閉舊的啟動視窗，再重新啟動。

啟動檔目前明確設定 FUZZY_DATA_MODE=local，不需 MySQL 即可使用第一章的四種練習題：一次函數代入、二次函數代入、合成函數、一次方程式。這是新增練習題庫，並非還原原始題庫，也未修改 MySQL 資料。

每題有 2 至 4 個解題步驟；每步有四扇門、一個正確選項。選錯留在原步驟，扣 25 HP 並透過原有 Fuzzy API 扣能力值。能力值服務失敗時固定扣 5。錯四次血量歸零後重生、換新題；能力值達 80 通關。保留提示和計時功能。

目前只有第一章提供題型，第 2 至 8 章尚無題庫。原始 MySQL 模式保留：取得相容題庫後，把啟動檔的 FUZZY_DATA_MODE=local 改成 FUZZY_DATA_MODE=mysql。原始題庫的解題選項仍須檢查是否包含 options，不能將練習模式的驗證視為原始題庫驗證。

驗證：600 組隨機題目的選項唯一性、每步唯一正解與最終答案一致性；Flask 首頁、設定、出題、錯誤參數和能力值 API；JavaScript 語法與四次扣血重生流程。
